# Inicio

Bóveda de referencia del sector para Tekla Structures 2025.

## Flujo de trabajo

**Modelado** → **Detallado** → **Plano de montaje**

- [[Modelado]]: cómo se modela cada pieza y qué criterios se siguen.
- [[Detallado]]: conexiones, soldaduras, planos de fabricación y acotado.
- [[Plano de montaje]]: planos de montaje, vistas y marcas.

## Soporte

- Parámetros compartidos: carpeta `04 Parametros`.
- Macros: carpeta `07 Macros`.
- Planos de ejemplo: carpeta `05 Ejemplos`.
- Instructivos internos: carpeta `06 Instructivos`.
- Índice completo: [[INDICE]].

## Cómo se usa

Para cada pieza hay una nota por etapa (`Pieza - etapa`). Cada nota termina con un
bloque **Flujo** que la une con las otras etapas de la misma pieza.
